# City Thumbnails

워너고트립 도시정보/주의사항 페이지에서 사용하는 도시 썸네일 이미지 모음입니다.

## 폴더 구조

```text
assets/
  city-thumbnails/
    런던.png
    파리.png
    ...
```

## 사용 예시

GitHub Pages를 켠 경우:

```html
<img src="/assets/city-thumbnails/런던.png" alt="런던">
```

다른 웹페이지에서 raw/CDN 형태로 사용하는 경우, GitHub에 업로드 후 아래 형태로 사용합니다.

```text
https://raw.githubusercontent.com/깃허브아이디/저장소명/main/assets/city-thumbnails/런던.png
```

또는 jsDelivr:

```text
https://cdn.jsdelivr.net/gh/깃허브아이디/저장소명@main/assets/city-thumbnails/런던.png
```
